Agendia

Sistema full stack de agendamento online para pequenos negócios — salões, barbearias, clínicas. Confirmação automática, lembretes por e-mail e WhatsApp, e painel multi-tenant com isolamento total de dados entre negócios. Fila assíncrona com Celery e Redis para as notificações, e validação de conflito de horário coberta por testes automatizados.

EventRank

Sistema full stack para avaliação e ranking de eventos, com foco em segurança e organização arquitetural. API REST em Java e Spring Boot, autenticação via JWT, versionamento de banco com Flyway e ambiente containerizado com Docker Compose. Frontend em React e TypeScript, com testes automatizados via JUnit.

CineVault

Aplicativo mobile para descoberta, organização e avaliação de filmes, com React Native e Expo, integrado à API do TMDB. Suporta múltiplas contas no mesmo dispositivo com dados isolados entre elas, listas de assistidos e quero-assistir, e avaliação pessoal de 0 a 10. Desenvolvido originalmente em equipe e evoluído com melhorias de estrutura, integração e distribuição do build Android.
